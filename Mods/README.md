Mods to tweak Overcooked! 2 behavior and make it more suitable to arcade

Based on BepInEx (5.4.23.5), which must be installed in Overcooked
(Beware on Linux & Steam: https://github.com/BepInEx/BepInEx/issues/1154#issuecomment-3273002052 )

* Extra checks to split chop vs wash action for each player
* Autoregister all 4 controllers on startup
* Automatically open "arcade" lobby and block users in it (cannot close)
