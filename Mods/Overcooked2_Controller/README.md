⚠️ Deprecated in favor of Overcooked2_NotifyInteractable

This mode refines the controls to dis-assemble the Chop/Wash/Extinguisher actions into multiple ones.
It makes that each action also check for an extra event (a keyboard touch, but could be anything) to
become distinguishable.

So a controller that wishes to split those actions can use this mod and send the related events
together with the basic gamepad button (west).
